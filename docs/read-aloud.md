# 글 읽어주기

글 본문의 **읽어주기 켜기**를 누르면 위에 **처음부터 끝까지 읽기** 버튼이 나옵니다. 누르면 본문을 처음부터 끝까지 순서대로 읽으며 표·이미지·캡션을 건너뜁니다. 다시 누르면 처음부터 시작합니다. 켜기만으로 자동 재생하지 않습니다. 문단·제목·목록 옆의 개별 재생 버튼도 사용할 수 있습니다. 본문 화면에만 제공하며 편집기·댓글·메뉴는 읽기 대상이 아닙니다.

- 일시정지·이어읽기·정지와 닫기를 제공합니다. 이어읽기는 멈춘 읽기 구간부터 시작합니다.
- 현재 문장을 본문에서 강조하고 이전·현재·다음 문맥을 보여 줍니다. 이전·다음 문장 버튼으로 이동하며 전체 읽기에서는 문단 사이도 이어집니다.
- 속도는 0.75~3배이며 브라우저에 저장합니다. 재생 중 변경하면 다음 읽기 구간부터 적용합니다. 긴 문장은 180자 이내로 나누므로 같은 문장 안에서도 구간이 바뀔 수 있습니다.
- TOPCIT2의 기술 용어 발음 사전과 일반 텍스트 수식·단위·위아래 첨자 처리를 사용합니다. 표시 문장을 발음 문자열로 바꾸거나 수식을 실행하지 않습니다.
- 코드 블록·만화 DSL과 카드·도식·표·이미지·캡션·숨겨진 영역·닫힌 접이식 영역은 제외합니다. 인라인 링크는 표시된 설명을 읽고 URL 자체는 제외합니다. 이미지로 렌더한 LaTeX 수식의 인식은 지원하지 않습니다.
- 읽는 본문이 바뀌거나 접이식 영역이 닫히면 정지합니다. 읽어주기 끄기·글 이동·창 숨김·페이지 종료 때 재생, 버튼, 강조, 이벤트를 정리합니다. Escape로 정지하고 본문 재생 버튼에 초점을 돌려줍니다.

기기·브라우저의 한국어 음성을 사용합니다. 별도 유료 TTS API나 계정은 필요하지 않습니다. 한국어 음성이 없거나 API를 지원하지 않으면 안내하며 재생하지 않습니다. 음성 목록이 늦게 준비되는 경우 다시 재생할 수 있습니다. 한국어 음성과 실제 음질은 기기 설정에 따라 다릅니다.

원본은 [TOPCIT2 shared 음성 모듈](https://github.com/jhs512/topcit2/tree/549c25dbad96b9ddc511098136527437d9f143fc/shared)입니다. 원본 기능은 문단별 재생·문장 강조·문맥 표시·발음/수식 처리이며 Slog에서 문장 이동 버튼과 본문 범위 연결을 추가했습니다. 출처·라이선스 확인과 수정 범위는 `front/src/lib/business/vendor/topcit-speech/README.md`에 기록합니다.

`front/`에서 `pnpm test:speech`로 엔진·발음·수식 61개 검사를 실행합니다. `pnpm exec playwright test --config playwright.rendering.config.ts e2e/rendering/speech.spec.ts`는 저장 없는 fixture와 모의 음성으로 PC·모바일 동작·제외 영역·오류·정리를 검증합니다. 실제 소리 출력 검증과 모의 API 검증은 구분합니다.
