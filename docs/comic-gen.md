# Markdown에서 만화 쓰기

코드 블록 언어를 `comic-gen`으로 지정하면 코드 대신 제목·첫 컷 썸네일 카드 하나가 표시됩니다. 카드를 누르면 만화 뷰어가 열립니다.

````markdown
```comic-gen
제목: 요청과 응답
등장인물:
  web: {그림: 서버, 이름표: 웹 서버}
  db: {그림: 데이터베이스, 이름표: DB}
컷:
  - 인물: [web, db]
    대사: [{화자: web, 상대: db, 내용: '데이터를 부탁해!'}]
  - 구성: 이전
    인물: [{식별자: db, 표정: 기쁨, 든소품: 데이터}]
    대사: [{화자: db, 상대: web, 내용: '찾았어!'}]
  - 구성: 이전
    전달: [{주는인물: db, 받는인물: web, 소품: 데이터}]
  - 구성: 이전
    인물: [{식별자: web, 손모양: 인사손}]
    대사: [{화자: web, 내용: '고마워!'}]
```
````

게시물·PPT 보기와 기본/VS CODE 편집기의 **미리보기**에서 같은 방식으로 렌더링됩니다. 미리보기는 저장하지 않은 본문도 반영합니다. 원문 저장·Raw 보기에는 YAML이 그대로 남습니다.

뷰어는 코믹젠 기본 원본 배치와 읽는 순서를 유지합니다. PC에서는 넓은 모달, 모바일에서는 전체 화면으로 표시하며 배경 본문은 가려집니다. **화면 넘침 방지** 체크박스 옆에서 보기 크기(100%·150%·200%)를 선택합니다. 기본은 체크 상태와 100%이며, 체크하면 선택한 배율을 상한으로 각 컷의 크기를 기준으로 가장 큰 컷의 너비·높이가 읽기 영역 안에 들어오도록 비율을 유지해 줄입니다. 전체 컷 배치는 유지하며 나머지 컷은 세로 스크롤로 읽습니다. 체크를 끄면 선택한 배율로 표시하며 가로·세로 스크롤을 지원합니다. 체크를 바꿔도 선택한 배율은 유지됩니다. 컷의 왼쪽/오른쪽을 클릭하면 실제 좌표와 읽는 순서에 따라 이전/다음 컷으로 이동합니다. 이전·다음 버튼과 현재 컷 표시도 제공하며 읽기 영역에서는 ←/→ 키로 이동합니다. 드래그·두 손가락 확대 조작은 컷 이동으로 처리하지 않습니다. Enter/Space로 열고, Tab으로 이동하며, 닫기 버튼 또는 Escape로 닫으면 카드로 초점이 돌아옵니다. 한글 키·값을 기본으로 작성하며 기존 영어 문법도 호환됩니다. 한 객체에 같은 항목의 한글·영어 키를 동시에 쓰면 오류입니다. 한 글에 여러 `comic-gen` 블록을 넣을 수 있습니다. `<details>` 안에서도 동작합니다. 문법 오류는 해당 블록에만 표시되며 다른 만화와 문단은 유지됩니다. 예제 문법 자체를 보여주려면 위처럼 바깥 펜스를 백틱 네 개로 감싸세요.

Comic Gen **v0.5.0** 공개 렌더 전용 SDK와 선택형 뷰어를 버전 고정해 번들에 포함합니다. Slog는 공용 `mountComicCard`를 사용하며 별도 뷰어·컷 이동 구현을 유지하지 않습니다. 렌더 전용 모듈은 뷰어를 불러오지 않습니다. YAML 데이터만 해석하고 SVG를 이미지로 표시하므로 대사 속 HTML이나 JavaScript를 실행하지 않습니다. 최대 30컷, 입력 100,000자이며 임의 에셋 업로드는 지원하지 않습니다.

## 검증

`front/`에서 `pnpm exec playwright test --config playwright.rendering.config.ts`를 실행합니다. 포트 3007/8097에서 읽기 전용 고정 데이터를 사용하며 DB·계정·운영 글을 변경하지 않습니다. 게시물, 네 컷, 여러 블록, 오류 격리, 중첩 펜스, 접이식 영역, HTML 이스케이프, PC/모바일 카드·뷰어, 양축 넘침 방지·창 크기 변화·확대·스크롤·키보드·초점 복귀, 편집 중 오류 복구·삭제와 열린 뷰어 정리를 검증합니다.

## 컷 안 UML 다이어그램

클래스·시퀀스 등 Mermaid 문법은 컷의 `다이어그램`에 넣습니다. 인물·대사와 구분되는 칠판에 표시하며 컷 맞춤·스크롤·이전/다음 이동은 그대로 동작합니다.

````markdown
```comic-gen
제목: 회원과 주문
등장인물:
  teacher: {그림: 서버, 이름표: 선생님}
컷:
  - 인물: [teacher]
    대사: [{화자: teacher, 내용: 회원 한 명은 여러 주문을 만들어요.}]
    다이어그램:
      종류: 머메이드
      제목: 클래스 관계
      원문: |-
        classDiagram
          Member "1" --> "many" Order
  - 구성: 이전
    다이어그램:
      종류: 머메이드
      제목: 요청 순서
      원문: |-
        sequenceDiagram
          participant Client as 방문자
          participant Server as 서버
          Client->>Server: 요청
          Server-->>Client: 응답
```
````

Slog는 `renderComicAsync`를 기다린 뒤 카드를 표시합니다. 일반 만화는 추가 CDN 요청 없이 동작하고, 다이어그램을 처음 표시할 때 v0.5.0의 Mermaid 격리 로더와 Mermaid **11.17.2**를 CDN에서 불러옵니다. VS CODE의 Monaco AMD 로더와 충돌하지 않도록 별도 프레임에서 로드합니다. 네트워크·문법 오류는 해당 블록에 안내하며, 수정·삭제된 블록의 늦은 결과는 반영하지 않습니다. SDK 내부 렌더 자체는 AbortSignal을 지원하지 않습니다.

`다이어그램`은 다음 컷에 상속되지 않습니다. 원문은 최대 20,000자, `높이`는 선택 값 160~1200px입니다. 링크·외부 이미지·HTML·사용자 스타일은 지원하지 않습니다. 완료된 전체/개별 컷 SVG에는 다이어그램이 포함되며 SDK의 `exportPng`로 PNG를 만들 수 있습니다. Slog에는 별도 PNG 다운로드 버튼이 없습니다.
