# 코드 실험은 브라우저 안에서 컴파일하고 실행한다

독자가 슬로그 글의 실행용 코드 블록에서 여는 코드 실험은 슬로그의 하나의 기능으로 제공한다. 사용자 결정에 따라 컴파일·실행·추적을 모두 브라우저 안에서 처리하고 WebAssembly와 Web Worker를 활용하며, 코드 실행 서버나 외부 원격 실행 서비스는 사용하지 않는다. 언어 지원 범위보다 이 경계를 우선하므로 Rust·Go를 포함해 이 조건으로 지원할 수 없는 언어는 제외한다.

정적 런타임 자산 다운로드는 원격 코드 실행과 구분한다. 언어별 가능 여부는 실제 브라우저 실행으로 검증하며, 출력 실행과 단계별 메모리 시각화 지원도 따로 검증한다.
