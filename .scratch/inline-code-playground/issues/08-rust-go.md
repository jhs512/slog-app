# 08: Rust·Go 지원 또는 근거 있는 제외

**What to build:** Rust·Go의 브라우저 소스 컴파일 실험 결과에 따라 실행을 연결하거나 지원 대상에서 제외한다.

**Blocked by:** 01: 브라우저 컴파일과 시각화 후보 검증; 02: 실행용 웹 블록에서 팝업 실험 완주

**Status:** ready-for-agent

- [ ] 서버 컴파일이나 미리 만든 WASM 실행으로 성공 판정을 대체하지 않는다.
- [ ] 지원 시 소스 수정→브라우저 컴파일→실행→오류 표시를 팝업에서 검증한다.
- [ ] 미지원 시 실험 근거와 제약을 문서화하며 지원 UI를 노출하지 않는다.
