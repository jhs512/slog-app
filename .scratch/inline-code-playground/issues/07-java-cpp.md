# 07: 검증된 Java·C++ 실행 연결

**What to build:** 검증된 Java·C++ 후보를 동일한 팝업 실행 계약에 연결하거나 불가능한 후보를 명확히 제외한다.

**Blocked by:** 01: 브라우저 컴파일과 시각화 후보 검증; 03: 독립 패널 배치와 브라우저 설정 복원

**Status:** ready-for-agent

- [ ] 지원한 언어는 단일 파일 소스 컴파일·선입력·콘솔·진단을 실제 브라우저에서 완주한다.
- [ ] 실제 추적을 제공하는 경우에만 메모리 패널을 노출한다.
- [ ] 불가능한 언어는 이유와 증거를 남기며 허위 재생 버튼을 제공하지 않는다.
- [ ] 자산 배포·라이선스·기존 로그인 영향과 런타임 격리를 확인한다.
