# 01: 브라우저 컴파일과 시각화 후보 검증

**What to build:** 언어별 단일 파일 소스와 선입력을 브라우저에서 컴파일·실행하고 실제 지원 범위와 배제 근거를 기록한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Java·C·C++·JavaScript·TypeScript·Rust·Go 각각의 검증 또는 제외 근거가 있다.
- [ ] Rust·Go는 사전 컴파일된 WASM 실행과 브라우저 내 소스 컴파일을 구분한다.
- [ ] C 메모리·React DOM/VDOM·런타임 재사용의 실제 데이터와 격리 가설을 검증한다.
- [ ] 정적 자산·라이선스·최초 로딩·자산 크기·제약을 기록하고 원격 실행을 사용하지 않는다.
