# 실행 플레이북

## 완료 판정

명시된 실행용 코드 블록만 재생 버튼을 표시한다. 버튼이 여는 동일 페이지 팝업에서 원문을 실행하고 임시 수정·수동 재실행·선입력을 제공한다. 닫고 다시 열면 원문과 초기 실행 상태를 복원하고, 화면 설정만 보존한다. 결과 화면과 각 비주얼라이저는 독립 패널이며 레이아웃·표시·크기를 조절할 수 있다. 모든 컴파일·실행·추적은 브라우저에서 일어나며 원격 실행 요청이 없어야 한다. 실제 동작을 검증한 언어만 지원한다고 표시한다. 웹 결과의 기본 글꼴은 Pretendard다.

## 수행 원칙

- 사용자 지시로 민수가 직접 조사·설계·구현한다. 이 기능을 다른 에이전트나 철수에게 넘기지 않는다.
- PStack poteto-mode의 Principles를 읽고, figure-it-out과 architect의 단계를 적용한다. 다중 에이전트 설계는 사용자 지시에 따라 두 구조의 순차 검토로 대체한다. 독립 리뷰가 없는 결과는 독립 리뷰 완료라고 표시하지 않는다.
- 저장소 지시에 따라 PR 없이 main에 검증한 단위로 반영한다.

- [ ] Phase E: 실제 렌더링과 실행으로 전체 완료 판정을 확인하고 main 반영·배포를 검증한다.

## 처리량 점검

- Blocking first steps: 런타임이 브라우저 안에서 동작하는지와 실제 지원 범위를 먼저 확인한다. 서버 실행 후보는 제외한다.
- Independent workstreams: 사용자 지시로 분산하지 않는다. 원문 렌더링·작업 공간·엔진은 독립 단위로 검증한다.
- Shared mutable state: 작업용 checkout과 결정 기록의 쓰기 주체는 민수 하나다.
- Smallest safe decomposition: 공통 작업 공간은 하나로 유지하고 엔진별 구현만 adapter에 숨긴다. 아직 확인하지 않은 엔진은 기능 목록에 넣지 않는다.

## 판정 표기

VERIFIED는 실제 아티팩트에서 확인한 결과에만 사용한다. NOT VERIFIED와 INCONCLUSIVE는 통과로 처리하지 않는다. 단계별 문서가 구현 완료를 의미하지 않는다.
